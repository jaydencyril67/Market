# Neon Run

The Market repository has been repurposed into the first KingsHall web-game prototype.

## Game
A lightweight 3D endless runner built with React, Vite and Three.js.

- Move left/right
- Jump
- Dodge obstacles
- Collect coins
- Increasing speed
- Score and game-over loop
- Desktop keyboard controls
- Mobile touch controls

## Development

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
